
# Placement

Where the sandbox may run, among the sandboxes server\'s runners: passed as it is to each sandbox the session is given, read where the server places it (when it is made, and when it is made again after its runner is gone). Absent is anywhere. A session no runner meets fails to start, saying which constraint nobody meets.
